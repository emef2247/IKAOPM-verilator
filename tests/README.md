# Self-authored renderer regressions

The five small files in vgm/ and their csv/ counterparts are generated by
make_fixtures.py from explicit register bytes. They contain no game data or
ROM-derived instruments. The historical scale_rom1 filename is retained for
AGENTS/build-script compatibility; YM2151 has no instrument ROM and the voice
is an explicit algorithm7 single-operator sine.

Generate or verify fixture bytes with `python3 tests/make_fixtures.py`.
Different pre-existing files are not overwritten. tests/fixtures/ is supplied
local comparison material and is ignored, not part of these test runs.

Run `python3 tests/test_audio_pipeline.py build/obj_dir/ikaOPM_sim` for14
end-to-end cases; `python3 tests/test_prepare_rtl.py` for4 offline provenance
checks after RTL preparation. Three standalone C99 programs test bounded
VGM parsing, CSV metadata/errors and bus timeout/overflow. See AGENTS.md.

Successful numerical checks do not establish cartridge/analog equivalence.
